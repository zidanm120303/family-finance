# Page Specifications

## Auth

### Login

- Split screen.
- Kiri: brand story, ilustrasi keluarga, mini-stat cards, trust indicators.
- Kanan: form login email/username + password, remember me, lupa password, Google button dummy, daftar link.

### Register + Create Family

- Stepper: Akun, Data Keluarga, Preferensi.
- Form data akun dan keluarga.
- Role default: Kepala Keluarga.
- Toggle kategori default dan undang anggota nanti.

## App Shell

Semua halaman setelah login harus punya:

- Sidebar tetap.
- Header dengan title, subtitle/breadcrumb, search global, notification, profile chip.
- Family switcher card di sidebar.

## Dashboard

- Summary: total saldo, pemasukan bulan ini, pengeluaran bulan ini, sisa anggaran.
- Chart arus kas bulanan.
- Budget progress per kategori.
- Wallet summary.
- Transaksi terbaru.
- Donut pengeluaran per kategori.
- Aktivitas terbaru.
- Quick action buttons.

## Transaksi

- Filter: search, date range, type, category, payment method, wallet, status.
- Table transaksi lengkap.
- Summary panel kanan.
- Pagination.

## Tambah/Edit Transaksi

- Form lengkap sesuai schema.
- Upload attachment.
- Summary dampak saldo.
- Tips.

## Kategori

- Tab Pengeluaran/Pemasukan.
- Table kategori.
- Drawer detail kategori dengan icon picker dan color picker.

## Anggaran

- Summary cards.
- Filter bulan/tahun.
- Table budget per kategori.
- Chart limit vs realisasi.
- Card kategori perlu perhatian.

## Dompet

- Summary cards.
- Wallet cards.
- Balance chart.
- Quick actions.
- Recent wallet activities.

## Anggota Keluarga

- Family summary.
- Role summary.
- Members table.
- Buttons tambah, invite, kelola role.

## Laporan & Riwayat

- Tabs laporan dan riwayat perubahan.
- Report charts.
- Audit log table.
- Detail drawer before/after JSON.

# Asset SVG FamFinance

Semua SVG ini bebas dipakai sebagai base icon UI. Simpan ke `public/assets/svg` di Laravel.

- `logo-famfinance.svg` — logo utama.
- `icon-wallet.svg` — saldo/dompet.
- `icon-income.svg` — pemasukan.
- `icon-expense.svg` — pengeluaran.
- `icon-budget.svg` — anggaran.
- `icon-family.svg` — ilustrasi keluarga sederhana.
- `icon-category-health.svg`, `icon-lightning.svg`, `icon-wifi.svg`, `icon-shield.svg` — ikon kategori.

Font tidak disertakan sebagai file. Pakai CDN/import resmi Google Fonts untuk Inter dan Plus Jakarta Sans.
